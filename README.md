# 🛡️ Fake News Detector | AI Powered Truth Checker

**Live App:** https://fake-news-detector-final.streamlit.app

Made by Anushka Ban - 1st Year Student | B.Tech AI/ML Project

### About The Project
In today's world, fake news spreads faster than real news. This project uses Artificial Intelligence and Natural Language Processing (NLP) to identify whether a given news article is REAL or FAKE.

Just paste the news text and get instant result with confidence score.

### ✨ Features
- 🚀 Instant Detection - Paste any news text and check Real vs Fake in 2 seconds
- 🧠 Smart Model - Uses TF-IDF + Machine Learning (Logistic Regression) with 92% Accuracy
- 💻 Built with Python and Streamlit - Clean and Fast UI
- 🌐 100% Working Live Website - Hosted on Streamlit Cloud
- 📱 Works on Mobile & Laptop

### 🛠️ Tech Stack
- **Python** - Core Language
- **Scikit-learn** - Machine Learning Model
- **Streamlit** - Web App Framework
- **NLP (NLTK)** - Text Cleaning & Processing
- **Pandas & Numpy** - Data Handling

### 🚀 How to Run This Project
1. Clone the repository
   git clone https://github.com/anushkaban11/fake-news-detector
   cd fake-news-detector

2. Install dependencies
   pip install -r requirements.txt

3. Run the application
   streamlit run app.py
